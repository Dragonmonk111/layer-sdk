# Incident note — 2026-10-18: overnight reboot recovery + donor findings

Context: Windows host rebooted overnight. home-vb (WSL) auto-restarted
via systemd (g1-node.service, ~40s), fell ~80k blocks behind, hit the
known rc11 catch-up wedge (D6), and force_state_sync recovery then
surfaced two new issues. Chain stayed healthy on the other 4 seats all
night.

## Findings

### D8 — donor gRPC decode cap (fixed, rc12)
`StateSyncClient` used tonic's default 4MiB decode limit; snapshot
chunk 0 is now ~7.8MiB at height ~2.22M. Every donor rejected with
`decoded message length too large` → force_state_sync crash-looped.
Fix: `max_decoding_message_size(16MiB)` on the state-sync client
(state_sync.rs). Server already encodes up to 12MiB.

### D9 — donor-side truncated block records (mitigated joiner-side; root cause open)
Some donors intermittently serve `QueryBlock` responses that are
truncated mid-varint (client decode fails before any field prints):
- vahana (57.129.103.229): regular ~every-4th-block cadence —
  2223922/26/29/33/37 all truncated from vahana, byte-identical heights
  served clean by ovh-uk1.
- ovh-uk1 (51.195.201.74): isolated heights, so far exactly the
  snapshot-donated heights (2222922, 2223927).

39-byte proposal records verified as the NORMAL form (unsigned
proposal encode — signature carried by the certificate), so this is
NOT the unsigned-proposal theory. Working hypothesis: storage-layer
torn reads around snapshot export / journal rewrite on the serving
box (vendored-storage journal territory — same family as the upstream
BlobMissing prune issue). Needs: reproduce locally, dump the stored
item bytes for a bad height on the affected box, compare journal
section state.

Joiner-side mitigation (committed): a donor serving an invalid record
is skipped (logged as evidence); `select_anchor` still enforces
`min_anchor_agree` byte-identical payloads. A corrupt donor cannot
lower the quorum bound, only fail to contribute.

### Ops gap — donor diversity
Only two seats expose gRPC 9090 (ovh-uk1 publicly, vahana publicly);
Anatoly + POSTHUMAN firewall it. With `min_anchor_agree=2` and one
flaky donor, recovery is at the mercy of which heights the snapshot
lands on. GO for rc12 asks every seat to open 9090 to the other four
seat IPs. Ravi flagged this first (2026-10-17) — confirmed correct.
