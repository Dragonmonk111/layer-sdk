<objective>
Replace all `todo!()` and `unimplemented!()` panic sites in the CosmosMsg dispatch function and query parser with graceful `Err(...)` returns. This prevents a WASM contract that emits `CosmosMsg::Stargate`, `CosmosMsg::Any`, or any other unhandled variant from crashing the entire node process (issue #177). Also fixes the `/app/version` query panic.

Purpose: Eliminate all known panic-on-input paths reachable from contract execution or gRPC queries. A malicious or poorly-written contract must never be able to crash the node.

Output: `cosmwasm_msg_to_layer()` returns `Err(WasmError::UnsupportedCosmosMsg(...))` for all unhandled variants. `parse_app_query("version", ...)` returns `Err(QueryError::UnsupportedPath(...))`.
</objective>
