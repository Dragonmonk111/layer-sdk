## Decisions Made
- `CosmosMsg::Any` is a tuple newtype variant wrapping `AnyMsg`, not a struct variant — the plan's suggested pattern `CosmosMsg::Any { type_url, .. }` does not compile; used `CosmosMsg::Any(any_msg)` and accessed `any_msg.type_url` instead
- `CosmosMsg::Stargate` is deprecated (use `CosmosMsg::Any` instead per cosmwasm-std 2.x) but we explicitly handle it so legacy contracts using Stargate receive a descriptive error rather than a generic wildcard message
- Wildcard arm kept as final arm in the match to satisfy `#[non_exhaustive]` requirement on `CosmosMsg`
