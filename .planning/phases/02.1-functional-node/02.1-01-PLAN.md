4. **Cosmos query dispatch helper** — add a public function that Plan 02 will use to add a custom tower layer:
```rust
/// Handle a Cosmos SDK gRPC query by path dispatch.
/// Called from a custom tower service layer in main.rs.
pub async fn handle_cosmos_query<T: PersistentStorage + Send + Sync + 'static>(
    app: &Arc<Mutex<App<T>>>,
    chain_id: &str,
    path: &str,
    body: Bytes,
) -> Result<Vec<u8>, Status> {
    let query = parse_cosmos_query(path, body, chain_id)
        .map_err(|e| Status::invalid_argument(e.to_string()))?;
    let response = {
        let app = app.lock().await;
        app.query(query)
    };
    encode_cosmos_response(response)
        .map_err(|e| Status::internal(e.to_string()))
}
```
