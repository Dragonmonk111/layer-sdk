### Re-verification Gap Closure Summary

**Gap 1 (CLOSED): Cosmos SDK Query Dispatch**

The `let _ = (cosmos_app, cosmos_chain_id)` stub and the `_cosmos_query_wired` type-check closure are fully removed from main.rs. In their place:

1. `grpc.rs` now exports `CosmosQueryState<T>`, `CosmosQueryService<T>` (implements `tower_service::Service`), `CosmosQueryFuture` type alias, `handle_cosmos_request()` async fn, and `cosmos_query_router()`.
2. `CosmosQueryService::call()` delegates to `handle_cosmos_request()` which: strips the gRPC 5-byte frame prefix, dispatches to `handle_cosmos_query()`, and frames the response with `grpc-status: 0` on success or the appropriate error code on failure.
3. `main.rs` constructs `CosmosQueryState` (with `#[cfg(feature = "rocksdb")]` / `#[cfg(not(feature = "rocksdb"))]` type selection), calls `cosmos_query_router(cosmos_state)`, converts to `tonic::service::Routes::from(cosmos_router)`, then `GrpcServer::builder().add_routes(cosmos_routes).add_service(...)`.
4. The path prefix matching (`/cosmos.bank.`, `/cosmos.auth.`, `/cosmwasm.wasm.`, `/cosmos.tx.v1beta1.Service/Simulate`) correctly covers all query paths handled by `parse_cosmos_query()` in packages/cosmos/src/query.rs.

The axum Handler version conflict (axum 0.7 from tonic vs axum 0.8 from commonware-runtime) was resolved by implementing `tower_service::Service` directly and using `fallback_service()` instead of `fallback()`.

**Gap 2 (CLOSED): tools/tx-sender and e2e Flow**

1. `tools/tx-sender/src/main.rs` implements `deployer_key()` using `SHA256("slay3r-testnet-deployer-v1")[0..32]` — identical to `default_genesis()` in main.rs.
2. All three message types are implemented: `MsgStoreCode`, `MsgInstantiateContract`, `MsgExecuteContract`.
3. Transaction signing uses `cosmrs::SignDoc::new(..., FIXED_ACCOUNT_NUMBER=17).sign(key)` matching `layer_cosmos::FIXED_ACCOUNT_NUMBER`.
4. Proto types from `layer-proto` (prost 0.13, tonic 0.12 compatible) — `cosmos-sdk-proto` dropped due to prost 0.11/0.13 incompatibility.
5. Manual CLI arg parsing replaces clap (proc-macro2 version lock: 1.0.86 in workspace vs 1.0.106 required by clap 4.5+).
6. `scripts/testnet.sh` `cmd_e2e()` builds tx-sender unconditionally (errors if build fails), queries deployer balance, submits StoreCode, waits 3s, submits InstantiateContract, conditionally submits ExecuteContract and query if contract_addr is in logs.
7. No `"E2E test PARTIAL"` string remains in testnet.sh.
